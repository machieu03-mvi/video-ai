# Thông số giọng đọc chuẩn

**Trạng thái: CHƯA CHỐT — các trường dưới đây chưa được phê duyệt.**

| Thông số | Giá trị sau khi chốt |
|---|---|
| Tên giọng | Chưa chốt |
| Voice ID | Chưa chốt |
| Model / phiên bản | Chưa chốt |
| Ngôn ngữ / chất giọng | Chưa chốt |
| Phong cách, nhịp đọc | Chưa chốt |
| Stability | Chưa chốt |
| Similarity | Chưa chốt |
| Các thông số khác của model | Chưa chốt |
| Tệp nghe mẫu đã duyệt | Chưa có |
| Ngày người dùng chốt | Chưa có |
| Phạm vi sử dụng / ngoại lệ | Chưa chốt |

Sau khi người dùng duyệt giọng, điền các trường phù hợp với model thực tế và dẫn đến tệp mẫu trong `mau_thu/`. Các thông số không được model hỗ trợ ghi “không áp dụng”. Không ghi API key tại đây.
